# DESIGN STUDY

自分専用のデザイン学習ポータル。Web Archive・ひとりガントと同じ Supabase プロジェクト・同じアカウントで使い、進捗と貼り付けた教材を PC とスマホで同期します。

## はじめに一度だけ
1. Supabase の SQL Editor に `supabase/schema.sql` を貼り付けて Run
2. GitHub にこのフォルダを push
3. Vercel で「Add New → Project」からこのリポジトリを Import（設定はそのままで Deploy）

## 手元で動かす
```
npm install
npm run dev
```
